# Circulos de Cuidado

Proyecto base con una separación clara entre backend y frontend.

## Stack recomendado

- Backend: Node.js + Express + TypeScript
- Frontend: React + Vite + TypeScript

## Estructura

```text
circulos-de-cuidado/
├── backend/
│   ├── src/
│   ├── config/
│   └── tests/
└── frontend/
    ├── src/
    └── public/
```

## Comandos rápidos

```bash
npm install
npm run dev:backend
npm run dev:frontend
```

## Objetivo

Este repositorio sirve como base para comenzar el desarrollo de una aplicación con arquitectura simple y mantenible.
