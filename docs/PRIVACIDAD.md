# Política de Privacidad

Fecha: 2026-08-12

Esta Política de Privacidad describe cómo "Círculos de Cuidado" recopila, usa, almacena y protege los datos personales de las personas que utilizan la plataforma.

1. Introducción

- Responsable: el equipo de Círculos de Cuidado.
- Alcance: aplica a los servicios ofrecidos a través de las aplicaciones y API del proyecto.

2. Datos que recopilamos

- Datos de identificación: nombre, email, avatar (opcional).
- Datos del perfil de cuidador: edad, relación con la persona cuidada, enfermedades o condiciones relevantes, fase del cuidado, geografía y disponibilidad horaria.
- Datos de autenticación: hash de contraseña, tokens de sesión (no almacenamos contraseñas en texto claro).
- Datos de uso: registros de actividad, logs de eventos y métricas de uso anónimas.
- Datos opcionales: información que el usuario decide añadir en su perfil o durante interacciones (notas, preferencias, etc.).

3. Finalidades del tratamiento

- Proveer y mejorar el servicio (autenticación, emparejamiento, gestión de círculos).
- Comunicación con el usuario (notificaciones, emails transaccionales).
- Investigación y mejora del producto usando datos agregados y anónimos.

4. Base legal (GDPR básico)

- Consentimiento: para procesar datos sensibles que el usuario aporte voluntariamente.
- Ejecución de contrato: para el registro y la prestación del servicio.
- Interés legítimo: para seguridad, prevención de abuso y mejora de la plataforma (siempre con medidas de minimización y anonimización).

5. Minimización y anonimización

- Solo recopilamos los datos estrictamente necesarios para las finalidades declaradas.
- Cuando sea posible, los datos se almacenan de forma anonimizada o pseudonimizada (por ejemplo, para análisis y métricas).

6. Derechos del usuario

- Acceso: el usuario puede solicitar copia de sus datos.
- Rectificación: corregir datos inexactos o incompletos.
- Supresión (derecho al olvido): el usuario puede solicitar la eliminación de su cuenta y datos personales.
- Portabilidad: solicitar una exportación de sus datos en formato legible (JSON/CSV) cuando aplique.
- Restricción y oposición: oponerse a ciertos tratamientos basados en intereses legítimos.

Procedimiento: las solicitudes deben enviarse a la dirección de contacto indicada en la sección 11. Responderemos en plazos razonables y conforme a la legislación aplicable.

7. Conservación de los datos

- Conservaremos los datos personales mientras la cuenta esté activa y durante los períodos legales requeridos.
- Datos anonimizados para análisis pueden conservarse indefinidamente.

8. Seguridad

- Medidas técnicas y organizativas: cifrado en tránsito (TLS), hashing de contraseñas, control de accesos, backups seguros.
- Revisión periódica de accesos y políticas de seguridad.

9. Compartición con terceros

- Servicios externos: podemos integrar servicios de envío de correos, análisis anónimo o proveedores de autenticación. Solo compartimos lo necesario y mediante contratos que aseguren protección de datos.
- No vendemos datos personales.

10. Transferencias internacionales

- Si los datos se transfieren fuera del EEE, se usarán mecanismos legales adecuados (cláusulas contractuales estándar u otros mecanismos compatibles).

11. Contacto y responsables

- Contacto para privacidad: equipo de Círculos de Cuidado (agregar contacto real si procede: correo o issue template).

12. Cambios en la política

- Nos reservamos el derecho de modificar esta política. Publicaremos la versión y fecha de actualización en este documento.

13. Entregable y cumplimiento

- Entregable: `docs/PRIVACIDAD.md` (este archivo).
- Esta versión cubre los requerimientos básicos de GDPR: consentimiento, minimización, derecho al olvido y seguridad.
