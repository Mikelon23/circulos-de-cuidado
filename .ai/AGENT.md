# Instrucciones del agente

## Tareas del roadmap

Cuando el usuario solicite ejecutar una tarea del roadmap:

1. Lee completo `.ai/tareas.md` antes de empezar; es la fuente oficial del roadmap.
2. Busca la tarea por su `id` exacto y revisa las tareas anterior y siguiente para entender el contexto.
3. Antes de cambiar código, revisa la arquitectura del repositorio y la documentación relacionada.
4. Implementa solo lo necesario y conserva las funcionalidades existentes.
5. Valida los cambios. Al finalizar, crea un commit con Conventional Commits y haz push.

Respeta el formato de tareas definido en `.ai/tareas.md`; no dupliques aquí el roadmap.
